# LISEZ-MOI — Comment lire cette bibliothèque (guide pour Ivo)

> Tu n'as PAS besoin de lire les 19 documents d'un trait. La bibliothèque est conçue pour qu'on ne lise que ce dont on a besoin au moment où on en a besoin.

---

## 🎯 Parcours express — 15 minutes (avant de décider quoi que ce soit)

| Ordre | Doc | Ce que tu dois en retenir | Temps |
|---|---|---|---|
| 1 | `00-INDEX.md` | La carte + les 9 décisions produit déjà consignées | 3 min |
| 2 | `02-perimetre-fonctionnel.md` — sections 0 à 3 | Le modèle casquettes (Cadet/Aîné cumulables) + les règles RG1-RG12 | 7 min |
| 3 | `18-analyse-senior-plan.md` — sections 4 et 5 | La roadmap des tranches T0→T6 + **les 4 questions qui t'attendent** | 5 min |

## 🗂️ Le reste (docs 05 à 17) — lecture DIFFÉRÉE

Chaque spec se lit **au moment où on construit cette tranche** :

- **T1 Annuaire** → doc 04 (déjà dans le parcours)
- **T2 Parrainage** → docs 05 + 07
- **T3 Communication** → docs 06 + 08
- **T4 Communauté** → docs 09 + 10 + 13
- **T5 Back-office** → docs 11 + 12 + 15 + 16
- **T6 IA** → doc 17 (+ les sections EXTENSION IA dans 04/09/11/12/14)
- **Alumni/Offres** → doc 14 (T4/T5)

## ❓ Les 4 questions auxquelles répondre en lisant (doc 18 §5)

1. **Déploiement** du front : serveur de l'école ? Railway/Vercel ?
2. **Nom** : « Parr'Innov » (cahier des charges) ou « EMSP Connect » (docs/code) ?
3. **Quota de 5 cadets** par Aîné : confirmé ?
4. **Bouton d'aide direct pour L1 en difficulté** hors binôme : ma recommandation est NON en V1 — tu tranches ?

## 📝 Mini-lexique des termes qu'on a inventés

| Terme | Signification |
|---|---|
| **Casquettes** | Cadet et Aîné sont cumulables : en L2 tu gardes ton aîné ET tu guides tes cadets |
| **RG1-RG12** | Les règles de gestion, numérotées et traduites en comportements d'écran précis |
| **Candidature Aîné** | Le interrupteur ON/OFF dans ton profil : « je suis ouvert à être Aîné » |
| **Famille** | Groupe automatique : un Aîné + tous ses cadets qui discutent ensemble |
| **Cercle** | Groupe libre créé par un étudiant, peuplé uniquement de ses relations actives |
| **Tranches T0→T6** | L'ordre de construction : socle → annuaire → parrainage → communication → communauté → back-office → IA |
| **MSW** | Mock Service Worker : le front tourne avec de fausses données conformes, en attendant le backend |
| **DoD** | Definition of Done : les 7 cases qu'une tâche doit cocher avant d'être « faite » |
| **ChipIA** | L'étiquette obligatoire sur tout ce que l'IA suggère (« Généré par IA ») |
